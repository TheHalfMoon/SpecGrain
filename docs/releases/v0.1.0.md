# SpecGrain v0.1.0

**Big ideas. Small specs. Proven software.**

v0.1.0 is SpecGrain's first public alpha release: a dependency-light deterministic control plane for refining, bounding, scheduling, packaging, verifying, and proving small software changes without making an AI model or coding agent the source of truth.

## Shipped capabilities

- immutable recursive SpecNode schema and semantic revision digests;
- lifecycle and refinement-tree validation;
- deterministic Definition of Grain readiness;
- repository-local `.specgrain/` store;
- dependency validation, blocker propagation, eligible Grains, and wave projection;
- bounded brownfield repository scan;
- explicit context budgets with required-context non-omission;
- digest-bound WorkPackets and structured execution-result self-reports;
- independent verification, changed-scope checks, evidence records, and `prove`;
- `quick`, `dmaic-lite`, `dmadv-lite`, `experiment`, and `controlled` method profiles;
- deterministic diff/drift/delivery metrics;
- bounded read-only GitHub Spec Kit import reporting;
- generic JSON/Markdown agent adapter boundary without provider execution;
- SpecGrainBench experiment ledger and contamination/comparability preflight;
- permanent cross-platform CI and tested zero-to-verified example.

## CLI

v0.1.0 ships these commands:

- `specgrain init`
- `specgrain check`
- `specgrain next`
- `specgrain scan`
- `specgrain prove`
- `specgrain import-spec-kit`

## Known boundaries

- No hosted service, dashboard, account system, telemetry requirement, or runtime model/provider dependency.
- Agent adapters normalize portable requests/results but do not invoke external agents.
- The CLI does not yet expose every internal API as an orchestration command.
- Spec Kit import produces a reviewable conversion report; it does not automatically create SpecNodes or mutate source repositories.
- SpecGrainBench has no published controlled multi-arm empirical dataset in v0.1.0; no benchmark winner is claimed.
- Verification correctness depends on the quality and independence of the checks supplied by the caller.

## Installation

Python 3.11 or newer is required.

```bash
python -m pip install "https://github.com/TheHalfMoon/SpecGrain/archive/refs/tags/v0.1.0.zip"
```

The runtime dependency list is empty.
