# SpecGrain v0.2.0

**Big ideas. Small specs. Proven software.**

v0.2.0 is a backward-compatible authoring release. It makes Specification 017's already-verified native root-DRAFT authoring path available through the versioned public product without expanding execution authority.

## Added since v0.1.0

- public `create_draft_spec` API for creating one validated native root SpecNode in state `DRAFT`;
- `specgrain draft` CLI command with required title/outcome, optional rationale, deterministic text/JSON output, and semantic revision reporting;
- deterministic lowest-unused positive IDs in the `SG-000001` through `SG-999999` range;
- create-if-absent local persistence that refuses to overwrite an existing spec artifact.

## CLI

v0.2.0 ships these commands:

- `specgrain init`
- `specgrain draft`
- `specgrain check`
- `specgrain next`
- `specgrain scan`
- `specgrain prove`
- `specgrain import-spec-kit`

## Authoring boundary

A newly created native spec is intentionally `DRAFT`. The release does not synthesize acceptance criteria, change surfaces, evidence requirements, Grain readiness, or execution authority. Recursive child refinement remains outside the CLI authoring surface in v0.2.0.

## Preserved trust boundaries

- No hosted service, dashboard, account system, telemetry requirement, or runtime model/provider dependency.
- No PyPI or other package-registry publication is claimed by this release.
- Agent adapters remain portable request/result normalization boundaries and do not invoke external agents.
- Spec Kit import remains read-only and does not mutate source repositories or silently promote legacy tasks.
- SpecGrainBench still has no published controlled multi-arm empirical dataset; no benchmark winner is claimed.
- Runtime third-party dependency count remains zero.

## Installation

Python 3.11 or newer is required.

```bash
python -m pip install "https://github.com/TheHalfMoon/SpecGrain/archive/refs/tags/v0.2.0.zip"
```

Release tag: `v0.2.0`. The canonical release source revision is the exact Git commit referenced by that tag and GitHub Release. Specification 018 closeout records exact publication, asset-digest, and historical-release preservation evidence after the release exists.
